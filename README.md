## Instruções para uso
1- instale o banco sqlite.
2- Na ide adicione o driver sqlite-jdbc-3.54.1.0.jar
2.1 - Como adicionar o driver pelo Intelij:
Vá em file -> project structure... ou digite ctrl+Alt+shift+s
Depois vá em module e, em seguida, clique em + e importe o driver.
3- para executar o sistema vá em src->app->Main. 
As operações com as enquetes e votos nessita de indicar o Id da enquete ou opção.
Você consegue os ids nas opções listar enquete e listar opções.
